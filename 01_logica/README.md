# Lógica e Orientação a Objetos (POO)

Este diretório contém meus estudos e práticas de Programação Orientada a Objetos em Python.

## Tópicos abordados:
- Introdução à POO (Classes, Objetos, Atributos e Métodos)
- Os 4 pilares da POO (Encapsulamento, Herança, Polimorfismo e Abstração)
- Projetos práticos com menus interativos (Sistemas de Reservas, Formatadores de Frases, etc.)
- Tratamento de exceções (try/except)
